# Origem dos ativos de marca

Ativos originais, copiados sem redesenhar ou aplicar cores da Akuris. As marcas pertencem aos respectivos fornecedores; sua exibição identifica a integração, sem sugerir parceria ou certificação.

- `github.svg`: GitHub Invertocat, pacote oficial [GitHub Logos](https://brand.github.com/foundations/logo), arquivo [GitHub_Logos.zip](https://brand.github.com/GitHub_Logos.zip).
- `entra.svg`: pacote [Microsoft Entra architecture icons](https://learn.microsoft.com/en-us/entra/architecture/architecture-icons), versão outubro de 2023.
- `intune.svg`: pacote oficial [Azure architecture icons](https://learn.microsoft.com/en-us/azure/architecture/icons/), versão V24.
- `microsoft365.svg`: símbolo corporativo Microsoft de quatro cores, não o ícone do Microsoft 365 Copilot. [Ativo oficial](https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg).
- `sharepoint.svg`: [Microsoft Fabric product icon](https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/sharepoint_48x1.svg).
- `onedrive.svg`: [Microsoft Fabric product icon](https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/onedrive_48x1.svg).
- `google-drive.png`: [diretrizes de marca Google Drive](https://developers.google.com/workspace/drive/api/guides/branding), [ativo Drive 2026](https://www.gstatic.com/images/branding/productlogos/drive_2026/v2/web-64dp/logo_drive_2026_color_2x_web_64dp.png).
- `aws.png`: [ícone original servido pelo site AWS](https://a0.awsstatic.com/libra-css/images/site/touch-icon-ipad-144-smile.png).

`aws-read-only.json` é o template CloudFormation da integração, não um ativo de marca.
